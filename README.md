# slotMachine
 
Una máquina slot hecha como proyecto para la materia **DOPO**.
 
La idea es sencilla: se gira, salen símbolos y se gana o se pierde. Detrás de eso hay un ejercicio de diseño orientado a objetos, los detalles se pueden encontrar en lo pdf de cada ciclo.
